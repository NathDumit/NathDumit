How to understand a legacy database when nobody knows how it works

An old system stores bookings in .dbf files, with no data dictionary and nobody left who designed it. This walkthrough shows, with an invented schema, how to rebuild the table map just by looking at the data.

Portfolio project. Every example uses a fictional system and data; no real company, client, system or value appears here. What is real is the method.

Four tables. Click a step below to see the test that reveals each part of the map.

The six steps

Traps the method catches

A key that looks unique and is not; a status code that means "cancelled"; an empty field that depends on the year; duplicates from reprocessing.

What comes out at the end

A map of tables and links, a list of discovered business rules and a list of questions to validate with the business, without inventing what the data does not prove.
