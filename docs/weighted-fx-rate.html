Which exchange rate should we use to buy the dollars for invoices due today?

Each dollar invoice has its value fixed at the exchange rate of the issue date. Treasury needs a single number to decide the purchase. The simple average misleads: it treats a US$ 100 invoice the same as a US$ 10,000 one. The value-weighted average answers the right question: how many reais, on average, has each dollar already cost?

Portfolio project. Every example uses a fictional system and data; no real company, client, system or value appears here. What is real is the method.

Guardrails that prevent an expensive mistake

Invoices whose rate falls outside a plausible range are flagged and can be excluded before the calculation, because a mistyped value (for example 0.56 instead of 5.60) distorts the purchase. The formula and the guardrails have automated tests.

weighted_rate = sum(usd_amount * rate) / sum(usd_amount)
suspect = ~rate.between(RATE_MIN, RATE_MAX)   # flags, does not delete
